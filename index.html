3.3. Version Control Systems Komut Sözlüğü

3.3.6 & 3.3.7 Temel & Dosya Komutları

git config --global user.name: Kullanıcı adı
git init: Depo başlatır
git clone <url>: Depoyu klonlar
git status: Durum raporu
git add .: Dosyaları sahneler
git rm <dosya>: Dosyayı kaldırır
git rm --cached: Takipten çıkarır
git commit -m "...": Kalıcı kayıt

3.3.4 & 3.3.9 Dallanma (Branching Features)

git branch: Dalları listeler
git checkout -b <dal>: Dal açıp geçer
git switch <dal>: Dala geçer
git merge <dal>: Birleştirir
git branch -d <dal>: Dalı siler

3.3.10 .diff & Tarihçe

git diff: Çalışma alanı farkları
git diff --staged: Sahne farkları
git log --oneline: Temiz geçmiş
git reset --soft HEAD~1: Son commit geri al

3.3.3 & 3.3.8 Uzak Depolar (GitHub & Remote)

git remote add origin <u>: Uzak depo bağla
git push -u origin <dal>: Buluta gönder
git fetch: Referansları güncelle
git pull: Değişiklikleri çek ve birleştir
